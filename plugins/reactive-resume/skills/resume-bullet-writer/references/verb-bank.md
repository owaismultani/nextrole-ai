# Verb bank and lint list

Choose a verb for what actually happened and the part the user actually played, not for how strong it sounds. Plain verbs read as human and specific; stacks of "power verbs" now read as machine-written.

## 1. Verbs that match ownership

| The user's part             | Verbs and phrasings                                                                          |
| --------------------------- | -------------------------------------------------------------------------------------------- |
| Primary owner               | led, ran, owned, designed, built, wrote                                                      |
| Shared lead                 | co-led, co-designed, co-wrote, jointly ran                                                   |
| Defined piece of team work  | "As one of [N] [role]s, built…", "Built [part] of [whole]", "Drove [X] within a team of [N]" |
| Supporting contribution     | contributed [what] to [project], partnered with [team] to…, supported [named result]         |
| Influence without authority | proposed, convinced, persuaded, set the standard adopted by…                                 |

Pair a team result with the user's own part: "As one of 6 engineers on the new mobile app, built offline sync; crash-free sessions rose…". Never put a team outcome under a solo verb unless the user confirms they owned it.

## 2. Plain verbs by intent

Prefer the earlier words in each group.

- **Made:** built, wrote, designed, created, launched, opened, set up, drafted, produced, founded, introduced, prototyped
- **Improved:** cut, reduced, raised, sped up, simplified, fixed, rebuilt, automated, standardised, redesigned, upgraded
- **Saved:** cut, lowered, eliminated, consolidated, shortened, prevented, recovered
- **Grew or won:** grew, won, sold, signed, closed, expanded, renewed, converted, secured, raised (funds)
- **Led people:** led, ran, managed, hired, trained, coached, mentored, supervised, chaired, delegated
- **Fixed:** fixed, resolved, diagnosed, debugged, stabilised, restored, repaired
- **Analysed or decided:** analysed, tested, measured, modelled, forecast, audited, investigated, chose, recommended
- **Persuaded or communicated:** negotiated, pitched, presented, briefed, wrote, documented, published, translated
- **Helped others:** taught, treated, cared for, advised, counselled, resolved, served, onboarded
- **Kept safe or compliant:** inspected, maintained, verified, enforced, prevented, documented, certified

Match the user's spelling: "standardised" (UK, AU, NZ, IN) or "standardized" (US, CA).

## 3. Duty language to rewrite

Flag these openers and rewrite around what changed:

- responsible for, duties included, tasked with, in charge of
- worked on, involved in, participated in, exposure to
- handled, dealt with
- helped (with), assisted (with), supported (with no named result)

"Helped" and "assisted" are acceptable only when they are the honest description; then say what was helped and how ("Assisted surgeons in [N] procedures a week as scrub nurse").

Filler quantities: replace "various", "multiple", "several", "numerous" with a count, or drop them.

## 4. Words to use sparingly

Allow each at most once per resume, and only when literally accurate. The problem is density plus vagueness, not any single word; several of these still appear on university verb lists.

- **Ornamental verbs:** spearheaded, leveraged, orchestrated, championed, pioneered (unless truly first), revolutionised, transformed, harnessed, fostered, cultivated, catalysed, propelled, elevated, empowered, bolstered, navigated, synergised
- **Vague verbs:** utilised (write "used"), facilitated (say what happened), drove (say what moved)
- **Buzz adjectives and phrases:** dynamic, dedicated, passionate, results-driven, proven track record, detail-oriented, cutting-edge, robust, seamless, innovative, strategic (as filler), key, crucial, pivotal, meticulous, intricate
- **Style words that spiked in AI text since 2024:** delve, showcase, underscore. The list shifts with each model generation, so don't treat any one word as proof of AI.

## 5. Structural tells

These patterns make a set of bullets read as generated even when every word is fine:

- Every bullet built as "Verb X, resulting in Y% Z".
- Trailing participle clauses: ", driving…", ", ensuring…", ", enhancing…", ", fostering…".
- Lists of three abstract nouns ("strategy, execution and delivery").
- "Not only… but also".
- All bullets the same length.
- Percentages with no baseline or time window.
- Suspiciously round or evenly spaced numbers (20%, 30%, 40%). This flags invented numbers, not real ones: if the user's actual figure is round, keep it exactly, and never change a number to look less generated.
- Metrics the person couldn't have measured from their seat.
- Generic objects: "cross-functional stakeholders", "various initiatives", "key projects".
- Heavy em-dash use (a weak signal only).

## 6. Fixes

- Name the actual object: the system, product, ward, course, client type or report.
- Use the plain verb for what happened.
- Vary sentence shapes; let some bullets carry no number.
- Keep the user's own domain vocabulary and acronyms that their field knows; expand internal-only acronyms.
- Read the set aloud. If it sounds like a brochure, cut adjectives first.
